# PDF Form Studio · עורך וממלא טפסי PDF

מילוי טפסים, הוספת **חתימה** ו**חותמת**, וייצוא PDF מוכן — **בלי להדפיס ובלי לסרוק**.
כל העיבוד קורה בדפדפן שלך; שום קובץ לא נשלח לשום שרת.

Fill PDF forms, add a **signature** and a **stamp**, and export a ready PDF —
**no printing, no scanning**. Everything runs locally in your browser; no file
ever leaves your device.

---

## מה זה פותר / Why

הבירוקרטיה מכריחה מחזור מייגע: להדפיס טופס → למלא ביד → לחתום/להחתים → לסרוק →
לשלוח. הכלי הזה מבטל את המחזור: טוענים את ה-PDF, ממלאים בהקלדה, מוסיפים חתימה
וחותמת עם העכבר, ומייצאים PDF חתום — בשניות. **תבניות** שומרות את מיקומי השדות
של טופס חוזר, כדי למלא אותו מיד בפעם הבאה.

## הפעלה / Run

מכיוון שהכלי משתמש ב-worker של pdf.js, יש להגיש אותו דרך שרת מקומי (לא לפתוח
`index.html` ישירות מ-`file://`). הפעלה בפקודה אחת:

```bash
bash start.sh          # ואז פתחו http://localhost:8080
# או בפורט אחר:
bash start.sh 9000
```

`start.sh` משתמש ב-`python3 -m http.server` (או ב-`npx http-server` אם אין
פייתון). אין שלב בנייה ואין התקנת תלויות בזמן ריצה — כל הספריות כבר בתיקיית
`vendor/`.

Because the tool uses the pdf.js worker, serve it over a local server (don't
open `index.html` from `file://`). One command: `bash start.sh`, then open the
printed URL.

## שימוש / How to use

1. **פתח PDF** — לחצו על הכפתור או גררו קובץ לחלון.
2. **טקסט** — בחרו את כלי "טקסט" ולחצו על המקום בטופס; הקלידו (תומך עברית ו-RTL).
3. **וי / איקס / תאריך** — כלים מהירים לסימון תיבות ולהוספת תאריך היום.
4. **חתימה** — ציירו חתימה עם העכבר/אצבע, או העלו תמונה. נשמרת בספרייה לשימוש חוזר.
5. **חותמת** — העלו תמונת חותמת; הרקע הלבן מוסר אוטומטית כדי שתשב נקי על הטופס.
6. **הזזה / שינוי גודל** — גררו פריט להזזה, משכו את הידית לפינה לשינוי גודל,
   `Delete` למחיקה. לחיצה כפולה על טקסט לעריכה.
7. **תבניות** — שמרו את פריסת השדות של הטופס, והחילו אותה שוב בפעם הבאה.
8. **ייצוא PDF** — מוריד קובץ PDF ממולא. הטקסט המקורי של הטופס נשאר מתחת (וניתן
   לבחירה); רק מה שהוספתם מוטבע מעליו.

## פרטיות ואחריות / Privacy & responsibility

- **פרטיות:** כל העיבוד מקומי בדפדפן. חתימות, חותמות ותבניות נשמרות ב-
  `localStorage` של הדפדפן שלך בלבד.
- **אחריות:** הכלי הוא כללי, לשימוש במסמכים שלך. החתימו/חתמו רק על מסמכים שאתם
  מורשים לחתום עליהם, והאחריות לנכונות התוכן היא עליכם.

## איך זה בנוי / How it works

- **`pdf.js`** מרנדר את עמודי ה-PDF ל-canvas לתצוגה.
- כל פריט שמוסיפים נשמר כ**שבר יחסי** של מידות העמוד (`fx,fy,fw,fh,fontFrac`),
  כך שהמיקום נכון בכל רמת זום.
- בייצוא, שכבת-העל של כל עמוד מצוירת ל-canvas ברזולוציה גבוהה (הדפדפן מטפל
  בעיצוב עברית ו-RTL בצורה מושלמת) ומוטבעת עם **`pdf-lib`** מעל העמוד — כולל
  טיפול בעמודים מסובבים (`/Rotate`). עמודים ללא תוספות נשארים ללא שינוי.
- אין שלב בנייה: JavaScript ואניל, מודולים על `window.PFS`, ו-`app.js` כמודול
  ES שמייבא את pdf.js.

### מבנה הקבצים / Layout

```
pdf-form-studio/
  index.html            שלד RTL, סרגל כלים, תצוגת עמודים, פאנלים
  styles.css            טוקנים מהקטלוג + עיצוב האפליקציה
  app.js                אתחול (מודול): ייבוא pdf.js, חיווט הכול
  js/
    pdf-view.js         רינדור עמודים + זום
    overlay.js          שכבת-על, מודל הפריטים, טרנספורמציות
    element.js          פריט חופשי (טקסט/תמונה)
    drag-resize.js      מנוע גרירה/שינוי-גודל (מותאם מ-image-slot.js)
    image-tools.js      עיבוד תמונה: הסרת רקע לבן, חיתוך, פד חתימה
    assets-library.js   חתימות/חותמות שמורות (localStorage)
    templates.js        שמירה/החלה של פריסת שדות
    exporter.js         הטבעה ל-PDF עם pdf-lib (מודע לסיבוב)
    store.js            עטיפת localStorage
  vendor/               pdf-lib, pdf.js, גופן Heebo — הכול מקומי
  assets/sample-form.pdf  טופס לדוגמה לבדיקה
  start.sh              שרת מקומי
```

## בדיקות / Verification

נבדק מקצה-לקצה עם דפדפן אמיתי (Chromium/Playwright): טעינת PDF, הוספת טקסט
עברי + וי + תאריך + חותמת, גרירה/שינוי-גודל/זום, ייצוא (טקסט הבסיס נשאר בר-בחירה),
שמירה+החלה של תבנית, ועמוד מסובב 90°.

## מגבלות ותוכניות עתידיות / Limitations & roadmap

- אחסון נכסים ותבניות מוגבל ל-~5MB (מגבלת `localStorage`). בהמשך: IndexedDB.
- בהמשך: מיזוג-דואר מטבלה/CSV להפקת מספר טפסים בבת אחת; סיבוב/סידור עמודים.
