# Fillo · הטפסים ממלאים את עצמם
> **Any form, filled in seconds.**

סורקים תעודת זהות **פעם אחת** — ומכאן כל טופס שנפתח **כבר ממולא**: השדות מזוהים
לפי משמעות (גם בסרוקים, עם OCR עברי), החתימה וכתב-היד האישי שלכם יושבים במקום,
תאריך של היום נכנס לבד, ות"ז שגויה נתפסת עוד לפני הייצוא. עובד כאפליקציה
מותקנת בטלפון: משתפים PDF מ-WhatsApp אל Fillo — ומחזירים אותו חתום לצ'אט.
כל העיבוד מקומי בדפדפן; שום קובץ לא נשלח לשום שרת.

Scan your ID **once** — from then on every form opens **already filled**:
fields are matched by meaning (scanned forms too, via Hebrew OCR), your
signature and personal handwriting land in place, today's date fills itself,
and a bad ID number is caught before export. Installable as an app: share a
PDF from WhatsApp into Fillo and send it back signed. Everything runs locally;
no file ever leaves your device.

**היכולות:** תיק אישי חכם (ת"ז→פרופיל) · מילוי-לפי-משמעות · זיכרון אוטומטי לכל
טופס · מסמכים אחרונים · מצב ראיון (שדה-אחרי-שדה) · מילוי בדיבור 🎤 · כתב-יד
אישי מסונתז · חתימות וחותמות · ציור חופשי · OCR עברי · מיזוג CSV מרובה ·
תבניות · מד השלמה + שומר ייצוא · ולידציית ת"ז · ניווט עמודים · קיצורי מקלדת ·
PWA אופליין + Share Target · גיבוי/שחזור · סנכרון ענן מוצפן (אופציונלי).

## מה זה פותר / Why

הבירוקרטיה מכריחה מחזור מייגע: להדפיס טופס → למלא ביד → לחתום/להחתים → לסרוק →
לשלוח. הכלי הזה מבטל את המחזור: טוענים את ה-PDF, ממלאים בהקלדה, מוסיפים חתימה
וחותמת עם העכבר, ומייצאים PDF חתום — בשניות. **תבניות** שומרות את מיקומי השדות
של טופס חוזר, כדי למלא אותו מיד בפעם הבאה.

## הפעלה מקומית / Run locally

מכיוון שהכלי משתמש ב-worker של pdf.js, יש להגיש אותו דרך שרת מקומי (לא לפתוח
`index.html` ישירות מ-`file://`). הפעלה בפקודה אחת:

```bash
bash start.sh          # ואז פתחו http://localhost:8080
# או בפורט אחר:
bash start.sh 9000
```

`start.sh` משתמש ב-`python3 -m http.server` (או ב-`npx http-server` אם אין
פייתון). אין שלב בנייה ואין התקנת תלויות בזמן ריצה — כל הספריות כבר בתיקיית
`vendor/`.

Because the served app uses a pdf.js Web Worker, serve it over a local server
(don't open `index.html` from `file://`). One command: `bash start.sh`, then
open the printed URL.

### גרסת קובץ יחיד (בלי שרת) / Single-file build

רוצים לפתוח בלי שרת? יש גרסה של **קובץ HTML יחיד** שמכילה הכול (כולל הגופנים
והספריות) ורצה בלחיצה כפולה או מכל אירוח:

```bash
node build.mjs      # יוצר dist/pdf-form-studio.html
```

פותחים את `dist/pdf-form-studio.html` בדפדפן — עובד גם מ-`file://`, בלי שרת ובלי
אינטרנט. (בגרסה הזו pdf.js רץ על ה-thread הראשי כדי להיות תואם CSP, מעט איטי יותר
מהגרסה עם ה-worker.) `dist/pdf-form-studio.artifact.html` הוא אותו דבר בפורמט
מתאים לפרסום כ-Artifact.

## שימוש / How to use

1. **פתח PDF** — לחצו על הכפתור או גררו קובץ לחלון.
2. **טקסט** — בחרו את כלי "טקסט" ולחצו על המקום בטופס; הקלידו (תומך עברית ו-RTL).
3. **וי / איקס / תאריך** — כלים מהירים לסימון תיבות ולהוספת תאריך היום.
4. **חתימה** — ציירו חתימה עם העכבר/אצבע, או העלו תמונה. נשמרת בספרייה לשימוש חוזר.
5. **כתב יד אישי** — לחצו **“כתב יד” → “אמן כתב יד”** וציירו כל אות פעם אחת;
   מאז, כשתקלידו טקסט הוא ייכתב **בכתב היד שלכם** (עם שונות טבעית). זה כתב היד
   שלכם על המסמכים שלכם — האחריות עליכם.
6. **חותמת** — העלו תמונת חותמת; הרקע הלבן מוסר אוטומטית כדי שתשב נקי על הטופס.
7. **הזזה / שינוי גודל** — גררו פריט להזזה, משכו את הידית לפינה לשינוי גודל,
   `Delete` למחיקה. לחיצה כפולה על טקסט לעריכה.
8. **תבניות** — שמרו את פריסת השדות של הטופס, והחילו אותה שוב בפעם הבאה.
9. **ייצוא PDF** — מוריד קובץ PDF ממולא. הטקסט המקורי של הטופס נשאר מתחת (וניתן
   לבחירה); רק מה שהוספתם מוטבע מעליו.

### 🔎 זיהוי שדות אוטומטי / Auto-detect fields

כשטוענים טופס, הכלי מנסה לזהות לבד איפה צריך למלא, ומציג **פאנל “שדות שזוהו”**
עם שורות קלט — מקלידים בשורה, וזה נכתב במקום הנכון על הטופס. שלוש רמות, בכנות:

- **טופס PDF עם שדות אמיתיים (AcroForm):** זיהוי מלא ומדויק של כל השדות.
- **PDF דיגיטלי עם שכבת טקסט:** זיהוי חכם לפי תוויות וקווים ריקים (מיטבי — ייתכנו
  אי-דיוקים; אפשר לגרור לתיקון).
- **טופס סרוק (תמונה בלי טקסט):** יש כפתור **“קרא עם OCR (עברית)”** שקורא את
  הסריקה עם Tesseract ומציע שדות (טיוטה — בדקו ותקנו; איטי יותר, זמין בגרסה
  המקומית בלבד). לחלופין: מילוי ידני + שמירת **תבנית** (שממלאת בשנייה בפעם הבאה).

השדות שזוהו מקבלים “שם שדה”, כך שהם עובדים מיד גם עם **הפרטים שלי** ועם **המיזוג
המרובה**.

### 🧠 זיהוי טופס חוזר — שדות קבועים / Form recognition

מגדירים שדות **פעם אחת** על טופס ושומרים כתבנית; הכלי לומד את "טביעת האצבע" של
הטופס (טקסט או תמונה). בפעם הבאה שתפתחו את **אותו טופס** — התבנית **מוחלת
אוטומטית**, ואם יש פרופיל פעיל ("הפרטים שלי") גם הפרטים מתמלאים לבד. פתחתם → מוכן.

### חוסכי-זמן מתקדמים / Power features

- **👤 הפרטים שלי (פרופילי דאטה):** בפאנל “מאפייני הפריט” תנו לכל שדה טקסט
  **“שם שדה”** (למשל `full_name`, `id`, `amount`). שמרו פעם אחת את הפרטים שלכם/של
  העסק בפאנל “הפרטים שלי”, ולחצו **“מלא בטופס”** — כל השדות המתויגים מתמלאים
  אוטומטית. אפשר להחזיק כמה פרופילים (אישי / עסק / לקוח).
- **⚡ מלא הכל (בקליק):** כפתור אחד שמחיל תבנית תואמת, ממלא את הפרופיל הפעיל,
  ומניח חתימה+חותמת ברירת-מחדל (⭐ בספריית הנכסים).
- **💾 גיבוי ושחזור:** מייצאים את כל ההגדרות (תבניות, פרופילים, חתימות, חותמות,
  כתב-יד) לקובץ אחד — ומשחזרים בכל מכשיר. `Ctrl+Z`/`Ctrl+Y` לביטול/שחזור פעולה.
- **🧬 מיזוג מרובה (Mail-merge):** תייגו שדות בטופס, לחצו **“מיזוג מרובה”**, הדביקו
  או טענו **CSV** ששורת הכותרת בו = שמות השדות, וקבלו **ZIP עם PDF לכל שורה** —
  כל הקבצים ממולאים בבת אחת, עם אותה חתימה וחותמת. מושלם לטיפול בהרבה טפסים זהים.

  דוגמת CSV:
  ```csv
  full_name,id,amount
  דנה כהן,111111111,10900
  משה לוי,222222222,8500
  ```

## פרטיות ואחריות / Privacy & responsibility

- **פרטיות:** כל העיבוד מקומי בדפדפן. חתימות, חותמות ותבניות נשמרות ב-
  `localStorage` של הדפדפן שלך בלבד.
- **אחריות:** הכלי הוא כללי, לשימוש במסמכים שלך. החתימו/חתמו רק על מסמכים שאתם
  מורשים לחתום עליהם, והאחריות לנכונות התוכן היא עליכם.

## איך זה בנוי / How it works

- **`pdf.js`** מרנדר את עמודי ה-PDF ל-canvas לתצוגה.
- כל פריט שמוסיפים נשמר כ**שבר יחסי** של מידות העמוד (`fx,fy,fw,fh,fontFrac`),
  כך שהמיקום נכון בכל רמת זום.
- בייצוא, שכבת-העל של כל עמוד מצוירת ל-canvas ברזולוציה גבוהה (הדפדפן מטפל
  בעיצוב עברית ו-RTL בצורה מושלמת) ומוטבעת עם **`pdf-lib`** מעל העמוד — כולל
  טיפול בעמודים מסובבים (`/Rotate`). עמודים ללא תוספות נשארים ללא שינוי.
- אין שלב בנייה: JavaScript ואניל, מודולים על `window.PFS`; הכול נטען כסקריפטים
  רגילים (pdf.js v3 UMD), כך שאפשר גם לארוז לקובץ HTML יחיד.

    pdf-view.js         רינדור עמודים + זום

    element.js          פריט חופשי (טקסט/תמונה)

    fields-panel.js     שורות הקלט של השדות שזוהו

  dist/                 קובץ HTML יחיד ומוטמע (נוצר ע"י build.mjs)
  assets/sample-form.pdf  טופס לדוגמה לבדיקה
  start.sh              שרת מקומי

## בדיקות / Verification

נבדק מקצה-לקצה עם דפדפן אמיתי (Chromium/Playwright): טעינת PDF, הוספת טקסט
עברי + וי + תאריך + חותמת, גרירה/שינוי-גודל/זום, ייצוא (טקסט הבסיס נשאר בר-בחירה),
שמירה+החלה של תבנית, ועמוד מסובב 90°.

## מגבלות ותוכניות עתידיות / Limitations & roadmap

- אחסון נכסים, תבניות ופרופילים מוגבל ל-~5MB (מגבלת `localStorage`). בהמשך: IndexedDB.
- OCR זמין בגרסה המקומית בלבד (כבד מדי לקובץ-היחיד). בהמשך: סיבוב/סידור עמודים; PWA.
