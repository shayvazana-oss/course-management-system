🔒 ייצוא מאובטח

מייצא את הטופס כתמונה שטוחה: הטקסט לא ניתן לבחירה/חילוץ, **השחרות באמת מסתירות** את מה שמתחת, והקובץ מוגן משינוי. מומלץ לפני שיתוף מסמכים עם מידע רגיש.

📱 התקנה כאפליקציה

Fillo נפתח כאפליקציה מלאה — אייקון במסך הבית, מסך מלא, ועובד גם בלי אינטרנט.

🧠 מה נלמד

Fillo לומד מכל ייצוא אילו ערכים חוזרים, וממלא/מציע אותם אוטומטית. כאן רואים ושולטים במה שנלמד.

💾 גיבוי ושחזור

כל ההגדרות (תבניות, פרופילים, חתימות, חותמות, כתב-יד) שמורות בדפדפן. גבו לקובץ, ושחזרו בכל מכשיר.

🔄 סנכרון בין מכשירים

מסנכרן כתב־יד, חתימות, חותמות ותבניות בין המכשירים שלך — מוצפן מקצה־לקצה (רק מי שיודע את קוד הסנכרון יכול לפענח). דרוש חשבון Firebase חינמי חד־פעמי. איך מקימים? ⓘ
1. היכנסו ל־console.firebase.google.com → “Add project” (שם כלשהו, אפשר לדלג על Analytics).
2. בתפריט → Build → Firestore Database → Create database → Start in test mode.
3. ⚙️ (Project settings) → תחת “Your apps” לחצו על </> (Web) → רשמו אפליקציה → העתיקו את apiKey ואת projectId.
4. הדביקו אותם כאן למטה, בחרו קוד סנכרון סודי משלכם, ולחצו “שמור והעלה”. במכשיר השני — אותם פרטים + אותו קוד → “משוך”.

🔒 פרטיות ואחריות

כל העיבוד מתבצע בדפדפן שלך. שום קובץ לא נשלח לשרת.
השימוש באחריותך: חתמו/החתימו רק על מסמכים שאתם מורשים לחתום עליהם.
✍️ ציור חתימה
צייר את החתימה עם העכבר או האצבע. הרקע יהפוך לשקוף אוטומטית.
🖊️ אימון כתב היד שלי
ציירו כל תו פעם אחת בכתב ידכם, בין הקווים כמו במחברת: אות רגילה נשענת על הקו התחתון ומגיעה עד העליון · י קטנה וגבוהה · ל עולה מעל הקו העליון · ך ן ף ץ ק יורדות מתחת לקו התחתון. כך כל אות תשמור על הגודל והמיקום האמיתיים שלה.
🖊️ כתיבה בכתב היד שלך
הקלידו טקסט כדי לראות אותו בכתב ידכם…
🗂️ תבניות טופס
תבנית שומרת את מיקומי כל השדות (טקסט, חתימה, חותמת) עבור הטופס הזה — כדי למלא אותו בשנייה בפעם הבאה.
🗂 תיקי קורסים
🧬 מיזוג מרובה — מילוי אצווה
מלאו טופס אחד לדוגמה, הדביקו את רשימת התלמידים מאקסל — והעמודות ימופו לשדות אוטומטית ("שם התלמיד" יזוהה כ"שם מלא" וכו'). התוצאה: ZIP עם PDF מוכן לכל שורה. חתימה וחותמת נשארות זהות בכל הקבצים.

💡 עזרה — כל מה ש-Fillo יודע לעשות
⚡ מילוי מהירהזינו את הפרטים פעם אחת (⚡ בפרטים שלי) — וכל טופס נפתח ממולא לפי משמעות השדות (עברית/אנגלית/ערבית), כולל סימון מין/מצב משפחתי/קופ״ח.
🪄 גזירת שדותכתובת אחת מתפצלת לעיר/מספר בית/מיקוד; שם מלא לשם פרטי+משפחה; שדה “סכום במילים” מתמלא לבד מהמספר (כולל אגורות).
🎯 מצב ראיון · 🎤 דיבורהכלי שואל שדה-אחרי-שדה (Enter/↓ הבא, ↑ קודם), או מלאו בדיבור.
✍️ חתימה · כתב-יד · חותמתציירו חתימה, אמנו את כתב-ידכם וכתבו איתו, או העלו חותמת. ✍️/⬤ בקליק על שורת חתימה/חותמת שזוהתה.
🖊️ כיסוי · השחרה · הדגשהכיסוי לבן לתיקון שגיאה מודפסת, השחרה להסתרת מידע, והדגשה צהובה שקופה.
🪪 ולידציה · שדות חובהת״ז, ח.פ/עוסק, אימייל, טלפון ותאריך נבדקים מיד; שדות חובה (*) מסומנים ומזהירים לפני ייצוא.
📄 ניהול עמודיםסובבו סריקה מוטה, מחקו עמוד מיותר, שנו סדר (▲▼ בממוזערות), או צרפו עמודים (צילום ת״ז/קבלה/PDF) — הכול לקובץ אחד.
🔒 ייצוא מאובטחייצוא כתמונה שטוחה — הטקסט לא ניתן לחילוץ והשחרות באמת מסתירות. מומלץ לשיתוף מידע רגיש.
🔁 מצב רצף · 🟡 מד השלמה“מצב רצף” משאיר כלי פעיל להנחה מרובה (Esc לעצירה); סימון ענבר ומד מראים מה נשאר.
⏱️ זיכרון · ☁️ סנכרוןטופס שמילאתם (כולל סיבוב/מחיקה/סדר) חוזר ממולא; סנכרון מוצפן בין מכשירים (הגדרות).
🧬 מיזוג מרובהטופס אחד + טבלת CSV = PDF לכל שורה בבת אחת — עם אותה חכמת מילוי (גזירת שדות, סכום במילים).
📲 בניידהתקינו כאפליקציה; שתפו PDF מ-WhatsApp אל Fillo — נפתח ממולא, וחוזר חתום לצ׳אט.
